
# Wolke Business – Business & Sales Analytics

## Project Overview
This project focuses on analyzing business sales performance, profitability, product performance, and customer trends using Tableau.

The project transforms raw sales data into meaningful business insights through data cleaning, KPI analysis, and interactive dashboard visualizations.

## Project Objectives
- Analyze overall business sales performance.
- Evaluate total profit and profit margin.
- Identify top-performing regions and product categories.
- Analyze payment method performance.
- Understand monthly sales and order trends.
- Build an interactive Tableau dashboard.

## Dataset Details
- **Dataset Name:** Wolke Business Sales Analytics Dataset
- **Original Records:** 2,000 Rows
- **Cleaned Records:** 1,984 Rows
- **Total Columns:** 12
- **Period:** 2023–2025

### Dataset Columns
1. Order ID
2. Order Date
3. Customer ID
4. Customer Name
5. Region
6. Product Category
7. Product Name
8. Quantity
9. Unit Price
10. Discount Percentage
11. Unit Cost
12. Payment Method

## Data Cleaning and Transformation
- Identified and removed 16 duplicate records.
- Analyzed missing values across the dataset.
- Handled missing numerical values using median imputation.
- Replaced missing categorical values with "Unknown".
- Created a separate cleaned dataset for Tableau analysis.
- Validated the cleaned dataset before visualization.
